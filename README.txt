CANDYVERSE AR — TEST PROJECT

UPLOAD THESE THREE FILES TO THE ROOT OF A PUBLIC GITHUB REPOSITORY:
- index.html
- CANDYVERSE_AR.usdz
- CANDYVERSE_AR_logo.png

PUBLISH:
1. Download and extract this ZIP.
2. Create a PUBLIC repository on https://github.com/ named candyverse-ar.
3. Upload the three files above to the top level of the repository.
4. Open Settings > Pages.
5. Set Source to "Deploy from a branch", branch "main", folder "/ (root)", then Save.
6. Wait for GitHub Pages to publish. The URL will look like:
   https://YOUR-USERNAME.github.io/candyverse-ar/
7. Open the published link on the iPhone in Safari and tap "View logo in AR".

IMPORTANT:
- This is a test build and has NOT been tested on a physical iPhone.
- The button relies on Apple's AR Quick Look opening the .usdz file.
- Keep the rear camera unobstructed and aim it toward the table. Do not put the phone face-down with the camera blocked.
- The model is a flat logo plane with transparent background, intended to appear as a floating logo, not thick/extruded letters.
